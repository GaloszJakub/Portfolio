About — 01

I write production-grade code, then audit it like a stranger wrote it. Five years between the two crafts has made me suspicious of every "it works on my machine."

I build full-stack web applications — usually TypeScript, React on the front, Node or Python on the back — and design the testing strategy that keeps them honest in production. End-to-end suites in Playwright, contract testing, performance budgets, the boring discipline that catches the bugs nobody else does.

Outside the editor: long walks around Warsaw with a film camera, slow coffee, slower jazz. Currently learning Rust the hard way.
